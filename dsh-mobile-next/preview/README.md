# 客户端界面预览

`panel.html` 是 `src/client.ts` 里设置页面板的**独立预览**，
用真实 DSH 数据（模拟 host 响应）渲染，不依赖 DSH 运行。

## 用途

客户端模块需要重启 DSH 才会加载（清单是启动时扫描的）。
这个预览让你**不重启也能看到界面长什么样**，方便调整样式。

## 打开

```bash
open preview/panel.html
```

明暗主题跟随系统。想看固定暗色，把 `@media (prefers-color-scheme: dark)`
改成 `@media all`。

## 与真实组件的差异

| 项 | 预览 | 真实组件 |
| --- | --- | --- |
| 渲染 | 手写 DOM | React `createElement` |
| 数据 | 硬编码示例 | `fetch('/mobile-access-next/*')` |
| 样式 | **完全相同**（逐字复制 STYLES） | 相同 |
| 交互 | 静态 | 可点（开关/生成二维码/撤销） |

样式是逐字复制的，所以视觉上与真实组件一致；数据与交互是模拟的。
