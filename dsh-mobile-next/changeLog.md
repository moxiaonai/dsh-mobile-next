## [0.2.2] — 2026-11-16

### 新增

- 新增局域网浏览器登录页：手机直接访问 `https://电脑IP:3444/`，未登录时显示配对入口，无需安装 App。
- 支持粘贴当前电脑的局域网配对链接或完整配对令牌；直接打开配对链接仍可自动配对，成功后进入真实 DSH 网页。
- 登录页支持移动屏幕、深浅色主题，以及无效或过期令牌、尝试次数过多、设备数量上限和连接超时提示。

### 修复与安全

- 修复直接访问局域网首页仅显示 `authentication required` 错误文本的问题；公开登录页返回 HTML，已登录用户继续访问 DSH。
- 损坏或伪造的会话 Cookie 不会获得访问权限；局域网首页回到登录页，受保护接口仍拒绝访问。
- 校验配对链接的来源与路径，令牌必须为完整的 43 字符；避免重复提交，连接超时后允许重试。
- 从其他网页点击登录链接时，仅允许局域网公开登录入口的顶层 GET / HEAD 文档导航；API、POST 和 WebSocket 不放宽跨站限制。
- 登录页使用 CSP nonce、禁止缓存、禁止第三方嵌入和不发送 Referrer 等保护；自动配对链接的令牌尽早移出地址栏与当前历史项。

### 兼容性与验证

- API、WebSocket 和其他受保护路径仍要求有效会话，电脑管理接口仍不能经网关调用。
- 独立 iroh 远程入口保持原有认证协议；此次修复不要求更新 Flutter / Android 客户端。
- 浏览器登录状态仅属于完成配对的浏览器，不与 App 共享；暂不持久化长期设备令牌或自动续期，会话过期后需重新配对。
- 补充浏览器配对页行为测试、网关认证边界测试及中英文使用说明。
- 本地验证：162 个测试通过、2 个原生集成测试跳过；类型检查、构建和包的独立安装与加载验证通过。
- GitHub Actions 的 Node 20、Node 22 插件检查与 npm 发布任务通过；手机真机的视觉与键盘体验不在此次验证范围内。

## [0.2.0] — 2026-11-12

### 移动接入基础能力

- 提供 DSH 电脑端插件，通过带设备配对认证的局域网 HTTPS 网关访问真实 DSH 页面。
- 提供实验性的 iroh 加密远程通道，需要电脑端原生组件和支持 iroh 的客户端。
- 提供侧栏「移动访问」面板，支持通道状态、配对二维码和链接、设备管理、连接诊断及网卡 / 端口 / CA 信息。
- 支持 host / client 双面插件分发，以及类型检查、测试、构建和独立包加载验证。
